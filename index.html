ARCHITECTURE CONCEPT

“Fungsi memanggil prosedur atau prosedur memanggil fungsi”

Pada aplikasi ini, event handler UI bertindak sebagai prosedur pengendali: ia memvalidasi input, mengirim pesan postMessage() ke Web Worker, lalu merender hasil saat menerima balasan. Di worker, prosedur handleMessage memanggil fungsi perhitungan (diskon iteratif/rekursif atau sorting). Pada algoritma rekursif, fungsi memanggil dirinya sendiri hingga kondisi dasar terpenuhi. Hasil kembali melalui pesan worker, kemudian prosedur UI memperbarui tabel, visualisasi, leaderboard, dan laporan.
